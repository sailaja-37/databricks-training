#  SQL Practice Queries – Week 1 Day 1

This folder contains the SQL queries I practiced during Day 1 of the Databricks Training program to strengthen my understanding of SQL concepts and database operations.

The practice was done using sample `Employee`, `Department`, and `Project` tables and focuses on learning how data can be retrieved, filtered, grouped, sorted, and analyzed using SQL queries.

A total of **65 SQL queries** were practiced covering fundamental and intermediate-level SQL concepts.

---

##  Key Concepts Practiced

###  Basic Queries
- Using `SELECT` statements
- Retrieving required columns
- Filtering data using `WHERE`

###  Pattern Matching
- Using `LIKE` operator
- Working with wildcards (`%`, `_`)

###  Date Queries
- Filtering records using dates
- Using `YEAR()` and `MONTH()`
- Date-based conditions

###  Aggregate Functions
- `COUNT()`
- `SUM()`
- `AVG()`
- `MIN()`
- `MAX()`

###  GROUP BY & HAVING
- Grouping records
- Aggregate-based analysis
- Filtering grouped data using `HAVING`

###  Sorting Data
- Using `ORDER BY`
- Ascending and descending sorting

###  Joins
- `INNER JOIN`
- `LEFT JOIN`
- Combining multiple tables

###  Nested & Correlated Queries
- Subqueries
- Correlated queries
- Salary-based analysis

###  Combined SQL Problems
- Multi-condition filtering
- Department-wise analysis
