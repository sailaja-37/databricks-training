# SQL Queries Practice

This section contains a collection of SQL practice queries using an Employee Management database.  
It covers important SQL concepts like data retrieval, filtering, grouping, sorting, and pattern matching.  

---

#  Key Concepts Practiced

##  SELECT Queries
- Retrieving employee records
- Displaying required columns
- Fetching employee details

##  WHERE Clause
- Filtering records using conditions
- Working with salary, department, city, and experience filters

##  GROUP BY Operations
- Grouping employee data department-wise and city-wise
- Performing summarized analysis

##  HAVING Clause
- Filtering grouped records
- Applying conditions on summarized results

##  TOP / LIMIT Queries
- Retrieving highest salary records
- Finding top experience holders
- Displaying limited results

##  DISTINCT Keyword
- Displaying unique departments, cities, salaries, and experience values

##  Comparison Operators
Using:
- `>`
- `<`
- `>=`
- `<=`
- `<>`

##  Logical Operators
Using:
- `AND`
- `OR`
- `NOT`

##  IN, NOT IN & BETWEEN
- Filtering multiple values
- Working with range-based conditions

##  LIKE Operator
- Pattern matching using:
  - `%`
  - `_`

- Searching records using text patterns
